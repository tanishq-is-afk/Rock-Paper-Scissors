# Rock-Paper-Scissors
🎮 Rock Paper Scissors Game

A classic Rock Paper Scissors game built with HTML, CSS, and JavaScript. Play against the computer and test your luck while keeping track of your score.

📌 Features
Choose between Rock, Paper, and Scissors
Computer generates a random move
Instant win, lose, or draw results
Score tracking for player and computer
Responsive and user-friendly design
Lightweight and easy to run

🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)

🚀 Getting Started
Prerequisites
You only need a modern web browser such as:
Google Chrome
Mozilla Firefox
Microsoft Edge
Safari


👨‍💻Installation
Clone the repository:
git clone https://github.com/tanishq-is-afk/Rock-Paper-Scissors.git
Navigate to the project folder:
cd rock-paper-scissors
Open index.html in your browser.


🎯 How to Play
Click on Rock, Paper, or Scissors.
The computer will randomly make its choice.
The game compares both choices and determines the winner.
Scores are updated automatically.
Continue playing as many rounds as you like.

🏆 Game Rules
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
If both choices are the same, the round is a draw
